Execution
Execute Query execute_query(query)
Executes a SPARQL query against the Knowledge Graph and returns the results.

Purpose: Serves a dual role: running the final query to obtain the answer, and providing iterative feedback throughout reasoning. Use it to test intermediate query drafts and diagnose errors in partial queries.
Use LIMIT to prevent fetching too much data for verification queries. After verification, the final query you return should be consistent with the question on whether LIMIT is needed.

Output Format: Table with the query result columns, or an error message if the query fails.
Input Schema
querystringreq The valid SPARQL query string to execute.
Output Format
Table with the query result columns, or an error message if the query fails.
Finish
Answer Question answer(kg, sparql, answer)
Provide your final SPARQL query and answer to the user question based on the query results. This function will stop the generation process.
Input Schema
kgstringreq The knowledge graph on which the final SPARQL query needs to be executed
sparqlstringreq The final SPARQL query
answerstringreq The answer to the question based on the SPARQL query results
Output Format
Stops the generation process and returns the final answer.
