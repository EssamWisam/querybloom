Ancestor Exploration explore_class_ancestors(class_uri, max_hops)
Find all ancestor (superior) classes of a given class URI by traversing subclass relationships. Returns results as a pandas DataFrame with class URIs and distances.
Input Schema
class_uristringreq Full URI of the class to find ancestors for (must be complete URI, prefixed forms like 'prefix:localName' are NOT allowed).
max_hopsnumberopt Maximum number of hops to traverse up the hierarchy (default: 5).
Output Format
▤ Table with columns:
ancestor_classlabeldistance
Descendant Exploration explore_subclass_tree(superclass_uri, max_depth, max_children, pretty_print)
Build a tree of all subclasses starting from a given superclass URI. Returns a dictionary where keys are class URIs and values are lists of their direct subclasses. Optionally prints a pretty tree visualization.
Input Schema
superclass_uristringreq Full URI of the superclass to start the tree from (must be complete URI, prefixed forms like 'prefix:localName' are NOT allowed).
max_depthnumberopt Maximum depth to traverse down the hierarchy (default: 5).
max_childrennumberopt Maximum number of children to consider at each level (default: 15).
pretty_printbooleanopt Whether to print a formatted tree visualization (default: True).
Output Format
◆ Dictionary:
tree→class_uri → subclass_uri[]
labels→uri → label string
