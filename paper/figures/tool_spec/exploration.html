Property Usage Exploration explore_property_usage(property_uri, limit, max_sample, include_class_prefixes)
Analyze how a property is actually used in the graph by sampling real triples. Infers domain and range from actual data rather than ontology annotations (which are often missing or inaccurate).

Purpose: Differentiate between linguistically similar properties by seeing which entity types they actually connect, and verify that a candidate property relates the expected types before committing it to the query.
Input Schema
property_uristringreq The full absolute URI of the property to analyze. Do not use prefixed/abbreviated URIs.
limitnumberopt Number of example usage patterns to return (default: 10).
max_samplenumberopt Maximum number of triples to sample for type analysis (default: 5000). Reduce if the endpoint times out.
include_class_prefixesstring[]opt Optional list of URI prefixes to restrict the domain/range types shown. Useful to filter out noise when the knowledge graph spans many namespaces.
Output Format
▤ Table with columns:
DomainDomain LabelRangeRange LabelExample SubjectSubject LabelExample ObjectObject LabelCount
Entity Relations Exploration explore_entity_relations(entity_uri, num_ents, limit)
Explore the relationships of a specific entity by listing all its incoming and outgoing connections.

Purpose: Useful when search alone has been inconclusive for resolving a relation mentioned in the question, as it reveals the full local graph structure around the entity.
Input Schema
entity_uristringreq The full absolute URI of the entity to explore. Do not use prefixed/abbreviated URIs.
num_entsnumberopt Number of sample neighbors to show per property (default: 3). Keep low to avoid large outputs.
limitnumberopt Total number of results to return from query.
Output Format

Attributes (literals)
propertydirectionexample_neighborsexample_neighbors_labels
