Class Search search_all_classes(search_term, limit)
Search for classes in the Knowledge Graph by name or concept. Uses hybrid retrieval (semantic + keyword) to find relevant classes. Low-relevance results are automatically pruned.

Purpose: Use natural-language terms from the question to find candidate class URIs.
Input Schema
search_termstringreq The concept, keyword, or class name to search for. Utilizes semantic search to find relevant matches.
limitnumberopt Maximum number of results to return (default: 10).
Output Format
▤ Table with columns:
class_urilabelcountscore
Instance Lookup lookup_class_instances(class_uri, search_term, limit, mode)
Retrieve instances of a specific class, optionally filtered by name.

Purpose: The primary way to resolve named entities mentioned in the question (e.g., 'France', 'Albert Einstein') to their URIs. First identify the entity's class via class search, then use this tool with the entity name as search_term.
Input Schema
class_uristringreq The full absolute URI of the class. Do not use prefixed/abbreviated URIs.
search_termstringopt Optional keyword to filter entities by label/name.
limitnumberopt Maximum number of entities to return (default: 10).
modestringopt Result mode: 'labels_only' (default) searches only entity label; 'all_attributes' searches across all literal values.
Output Format
▤ Table with columns:
entitydisplayLabelsearchPropsearchVal
Property Search search_all_properties(search_term, limit)
Search for properties in the Knowledge Graph by name or concept. Uses hybrid retrieval (semantic + keyword) to find relevant properties. Low-relevance results are automatically pruned.

Purpose: Find candidate property URIs. Use the domain and range columns to understand how the property connects different entity types.
Input Schema
search_termstringopt The concept, keyword, or property name to search for. Utilizes semantic search to find relevant matches.
limitnumberopt Maximum number of results to return (default: 10).
Output Format
▤ Table with columns:
property_urilabelaliasesdomainrangecountscore
